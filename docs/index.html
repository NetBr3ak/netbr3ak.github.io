Software (closed source)

  • Voxmill: offline transcription for Apple computers, built with Rust, whisper.cpp and Core ML. 7.74% word error rate on the 758 read-speech clips of the Polish FLEURS test set (Voxmill Pro, Whisper large-v3-turbo Q5_0, normalised text, measured by Tenzan Logic, September 2026).

Open source

  • BETON: a Claude Code plugin. After each Write, Edit or MultiEdit, it runs the installed linters and type checkers, and tests matched by file name. It also blocks shortcuts such as # noqa and skipped tests.
  • HDFour: A Rust library for reading HDF4 and HDF-EOS2 files, with Python and WebAssembly bindings. I check its output against the reference HDF4 C library.
  • gba: A Game Boy Advance emulator in C++23 and SDL3. I test its graphics and BIOS functions with small programs written for the emulator, without distributing game ROMs.
  • Planetary System Simulation: A two-body gravity simulator. SciPy calculates the orbits; the tests check conservation of energy and momentum and compare the period with Kepler’s third law.
  • core-chat: A chat client in Next.js with a Bun and Hono backend. Replies stream from Gemini on Vertex AI; a stand-in model lets the tests run without a cloud key.
  • Fruitend: An animated page built with HTML, CSS and JavaScript. The citrus slice is drawn with gradients; the built-in inspector shows the CSS rules behind the element you point at.
  • Cook Book Chronicles: A recipe site that recalculates ingredients for the number of servings and runs timers beside the cooking steps. It needs no build step.
  • withastro/astro #18660, merged: preload variable fonts when the requested weight range is inside the file's range.

Research

HSPMN is Python research code for an unpublished manuscript on hybrid language models. It compares a learned per-token gate with a frozen random gate for routing between a Gated DeltaNet recurrent stream and a Native Sparse Attention stream. I trained models on WikiText-103 at two scales, 140M and 350M; these are scale names, not exact parameter counts (recorded findings).

A later audit found a bug that shifted the training targets twice, so every recorded run learned to predict the token two places ahead, not the next token. The audit also found future-token access in the predictive-coding gate and automatic NSA block selection, and an incorrect Gated DeltaNet CPU recurrence. Version 5.1.0 fixes these defects; I have not yet run it at training scale (reproduction status).
